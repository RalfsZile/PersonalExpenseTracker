# Personal Expense Tracker

## Description
Personal Expense Tracker is a simple Python application
designed to help users manage their personal finances.

## Features
- Add income
- Add expenses
- View transactions
- Calculate total income
- Calculate total expenses
- Track current balance

## Technologies
- Python 3
- Git
- GitHub

## Installation
1. Clone the repository.
2. Open the project folder.
3. Run main.py using Python.
